Flare Confidential Compute · hackathon proof

Jorqeth settles creator commissions from a merchant's own records, in private.

A merchant funds an escrow. A Flare Confidential Compute extension evaluates each sale against the campaign rules inside a TEE and signs the result. This contract pays the bound creator the exact commission only when that signed result is eligible, and pays nothing otherwise. This page is a read-only replay of that already-proven behaviour.

Replay mode. Every number below is read live from the committed proof files evidence/positive-proof.json and evidence/negative-proof.json, regenerable with bash evidence/run-proof-gate.sh. No live chain call or trigger runs here.

Every other path refuses to pay

The same funded campaign, attacked and stressed from every angle. A legitimate refund is terminal and pays zero. Duplicate, infrastructure-unknown, timeout, and error-status outcomes are visibly distinct: they revert and stay retryable, so a genuine "no commission owed" is never confused with "we could not decide".

    Honest limitations

    • Runs on a local anvil devnet, not live Coston2. A production-attested FCC round trip there is externally blocked; the verifier mode is labelled simulated-attestation.
    • The TEE signature scheme is proven byte-for-byte against real Flare library code (tools/tee-signer + contracts/test/FccRealSignature.t.sol), which is the self-contained substitute for that blocked round trip.
    • Jorqeth proves what the agreed merchant source records, not objective attribution outside that source.
    • All amounts and records here are synthetic.
