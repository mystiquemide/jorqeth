# Security policy

Do not open a public issue for a suspected vulnerability. Email
`splashmediahub@gmail.com` with the affected component, impact, reproduction steps, and
any suggested fix. You should receive an acknowledgement within three business days.

Jorqeth is testnet software. The deployed token has no cash value and the current Coston2
evaluator uses a disclosed trusted signer. Do not use this deployment for production funds
or private customer data.
