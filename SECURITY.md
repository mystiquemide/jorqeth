# Security policy

Do not open a public issue for a suspected vulnerability. Email
`splashmediahub@gmail.com` with the affected component, impact, reproduction steps, and
any suggested fix. You should receive an acknowledgement within three business days.

Jorqeth is testnet software. The deployed token has no cash value and the live Coston2
FCE runtime uses supported simulated attestation rather than hardware-backed production
attestation. Do not use this deployment for production funds or private customer data.
